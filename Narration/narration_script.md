# Narration script

Voice: George, ElevenLabs Multilingual v2.

## 1. Hook & context

Two dots are travelling along the same graph. One comes from the left, and the other from the right. Both are heading toward the input two. Before either dot arrives, can you predict the height they are heading toward? Watch the dashed guides as the dots move closer.

Both dots head toward height four. Now look at the filled dot directly above input two. It sits at height one. So the nearby outputs approach four, while the output at two is one. In this lesson, we will learn to predict nearby behaviour, calculate a limit, and check whether a function is continuous.

## 2. What a limit means

The letter x is the input, and f of x is its output. The letter a stands for the input we are approaching. Capital L is the height the outputs approach. The expression on screen reads: the limit of f of x as x approaches a equals L.

A limit of L means that we can make the outputs as close to L as we want by taking x sufficiently close to a, with x different from a. For example, on the line x plus two, inputs approaching two give outputs approaching four.

A minus above the input means we approach from values smaller than a. A plus means we approach from values larger than a. These are the left-hand and right-hand limits. A two-sided limit exists when both sides approach the same value.

## 3. Read the graph

Follow the gold dot from the left. An input of one point five gives an output of three point five. At one point nine, the output is three point nine. Each output is closer to four.

Now follow the blue dot from the right. Two point five gives four point five, and two point one gives four point one. This side approaches four too. The open circle marks the missing point at height four.

The filled dot tells us which output the function actually assigns at two. Here that output is one. If we remove the filled dot, the function becomes undefined at two, but the dots travelling along the line still approach the same height. In both versions the limit is four.

## 4. Work it out

Consider x squared minus four divided by x minus two. Substituting two gives zero over zero, which is undefined. To understand the nearby behaviour, factor the numerator as x minus two times x plus two.

For every x different from two, the factor x minus two is nonzero, so we can cancel it. This leaves x plus two. That equality holds on both sides of two, while the original quotient stays undefined at two.

As x goes to two, x plus two goes to two plus two, which is four. The graph therefore follows the line x plus two with a hole at two comma four. The algebra and the graph predict the same height.

Now define a piecewise function: use the original quotient away from two, and assign the value four at two. The nearby graph stays exactly the same, and the new value fills the hole. At two, both the limit and the assigned value are four, so this new function is continuous there.

## 5. Check continuity

Continuity at an input a takes three checks. First, the function must have a value at a. Second, the two-sided limit must exist. Third, those two numbers must agree. Watch how changing the graph affects the checks at two.

On the complete line, the assigned value and the limit are both four. All three checks pass. Now move the filled point down to height one. The limit is still four, so the third check fails. This discontinuity is removable because assigning four repairs it.

For the jump, the left branch approaches four and the right branch approaches two. The filled dot gives a value of two, but the two one-sided limits disagree. The second check fails. Changing only the filled point cannot change either branch, so it cannot remove this jump.

## 6. Summary & credits

A limit describes the height the outputs approach. That height can differ from the output assigned at the exact input. Continuity needs a defined value and a limit, and those numbers must agree.

When you see a graph with a hole or a jump, ask three questions: what does the left side approach, what does the right side approach, and what value does the filled dot give?
